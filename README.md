## ⚙️ Getting Started

### 📥 Clone the Repository
```bash
git clone https://github.com/munnabiswas99/my-portfolio.git
```

### 📂 Navigate to Project
```bash
cd my-portfolio
```

### 📦 Install Dependencies
```bash
npm install
```

### ▶️ Run Development Server
```bash
npm run dev
```
